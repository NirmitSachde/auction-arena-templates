# Blade views

Laravel versions of `overlays/` and `stories/`, generated by `node tools/build-blade.mjs`. Don't edit these files by hand; change the HTML template or `tools/blade/*` and rebuild.

Each view is self-contained: it `@extends('frontend.layout.blank-layout')`, inlines its CSS and JS, and fills its markup from one `$aa` array built in the `@php` block at the top.

## youtube/ (live overlays)

- Drop-in replacements for the current YouTube overlay view. They use the same variables (`$tournament`, `$player`, `$basePrice`, `$tournament->latestActiveBiddingStatus`) and the same Echo channel and events (`player-change-event`, `bid-placed`, `bid-undo`, `player-sold`, `player-unsold`, `auction-finished`).
- The body is transparent. In OBS, add a Browser Source at 1920x1080 pointing at the route.
- SOLD / UNSOLD shows the stamp and top strip for 8 seconds, then resets to WAITING..., the same as the current overlay.
- If a team has a colour column, send it as `team.color` on `bid-placed` and map it in `tools/blade/overlay-data.blade.php`. Overlays 03 and 06 recolour to the bidding team; the default is `#e11d48`.

## player-card/ (story cards)

- Each view renders one 1080x1920 card plus a **Download PNG** button (html2canvas, the same library as the current poster page).
- Photos and logos must be same-origin or served with CORS headers, otherwise the browser refuses to export the canvas.
- Keep the important content between y = 250 and y = 1670. Instagram covers the top and bottom of a story with its own UI.

## Check before shipping

Lines marked `CHECK` in `tools/blade/overlay-data.blade.php` and `tools/blade/story-data.blade.php` are guesses at column or variable names, because the player-card controller wasn't available:

| Field | Guess |
| --- | --- |
| Tournament logo | `$tournament->tournament_image` |
| Team colour | `$team->color` (optional) |
| Story: buying team | `$team` |
| Story: sold price (points) | `$soldPrice` |
| Story: base price | `$basePrice` |

Fix them in those two files, then run `node tools/build-blade.mjs`.
